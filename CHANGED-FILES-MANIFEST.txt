BUILD FIX 5 — ROOT CAUSE, NOT A ONE-LINE WORKAROUND
The latest Actions compile showed that the item-ID borrow was already owned, but the active-animation tuple still retained a reference to the clip inside State.active. That reference remained live while the renderer mutated pendulum state, producing E0502.

The per-hand render setup now resolves all animation-dependent inputs inside one bounded match on State.active and returns only owned values: action ownership, blend weight, tuning/pendulum flags, and the sampled AttachmentFrame. The active Playback/Clip borrow ends before any pendulum state or kick mutation. The obsolete borrowed animation tuple and interpolated expression value (which had no consumers) are removed. Existing timing, ownership, effect activation, blend and frame-sampling semantics are preserved.

The physics-profile array remains explicitly typed as [PhysicsProfile; 2]. Per-hand item IDs remain cloned before state mutation. The regression suite now checks that active animation data is reduced to owned values before pendulum writes.
