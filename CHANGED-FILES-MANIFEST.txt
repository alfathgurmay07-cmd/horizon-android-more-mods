HAND POSE AND ITEM TRANSFORM PARITY
Retains the two-hand procedural idle and locomotion layers, action clip ownership, item grip-pivot conversion, editor/tuning transform flow, and attachment ordering already present in this working source.
The attachment path applies Pendulum tuning in the configured handSpace before or after item pre-transform, matching Punchy's renderer. Grip pivots are converted from Bedrock global bone pivots into item coordinates.

PENDULUM INPUT AND ACTION FEEDBACK
Movement sway now uses processed strafe/forward input (strafe * 1.5, -forward * 1.6), smoothed with Punchy's 1 - 0.7^(dt * 20) factor. Boat passengers suppress movement offsets, while walk-animation bob remains sourced from the player model for other passenger states.
Action playback now triggers the per-hand spring (stiffness 60, damping 15.5), with the original action impulse and kick. Pending kicks are preserved through initial state initialization and consumed only during a subsequent physics update. Clip effects for use_keyframes_v2, disable_pendulum, and disable_pendulum_physics follow the original distinction between disabling action feedback and fading pendulum influence.
